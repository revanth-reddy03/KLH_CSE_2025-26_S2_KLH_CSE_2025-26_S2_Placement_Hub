Current Project: Intelligent Student Record Search System

Project Description:
The Intelligent Student Record Search System is a Data Structures and Algorithms project designed to search and retrieve information from a collection of student profile documents. Instead of restricting search to only a roll number or name, the system treats the complete student profile as searchable text. Each document contains academic details, skills, project descriptions, certifications, interests, achievements, and career information. These documents form the student-record corpus used for pattern and string-matching experiments.

Problem Context:
Educational institutions maintain large collections of student information distributed across academic
records, skills, projects, certifications, achievements, and interests. As the number of student records
increases, manually locating relevant information becomes time-consuming. The project demonstrates how
string-matching algorithms can support efficient text-based retrieval across a student record corpus.

Search Problem:
Given a search pattern P and a collection of student record documents, the system searches the text of
each document to determine whether P occurs within the student profile.

KMP Implementation:
The Knuth-Morris-Pratt algorithm preprocesses the search pattern using the Longest Proper Prefix which
is also Suffix (LPS) array. The LPS information allows the search procedure to avoid unnecessary
comparisons after a mismatch.

Rabin-Karp Implementation:
The Rabin-Karp algorithm uses a rolling hash to compare the search pattern with windows of text.
Candidate matches are identified through hash values and can be verified character by character.

Corpus-Based Searching:
Each TXT document represents one student profile. The corpus contains multiple structured fields and
descriptive paragraphs so that pattern matching is evaluated on meaningful text rather than a single
hard-coded string.

Algorithm Comparison:
The same query can be processed using KMP and Rabin-Karp. The system verifies that both algorithms
identify the same matching documents and can record execution time and operation counts for comparison.

Expected Outcome:
The expected outcome is a Java-based search engine capable of scanning the student-record corpus and
identifying relevant documents for a given search pattern. The implementation provides a practical
demonstration of advanced string-matching concepts and creates a foundation for future extensions such
as fuzzy search, autocomplete, indexing, and ranking.
