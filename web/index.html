🧠 Algorithmic Subsystems Architecture

Subsystem 1: Information Retrieval & Text Search

Knuth-Morris-Pratt (KMP) & Z-Algorithm

Precomputes LPS / Z-boxes to skip redundant comparisons, executing linear-time O(N+M) keyword queries.

Aho-Corasick Multi-Pattern Screener

Trie automaton with failure links scanning entire resumes for 10+ required skills simultaneously in O(N+Matches) time.

Suffix Array & Edit Distance

Lexicographical suffix binary search for substring index queries, alongside Levenshtein DP typo tolerance.

Subsystem 2: Network Flow & Placement Allocation

Maximum Bipartite Matching (Kuhn's Algorithm)

Augmenting paths assign eligible candidates to distinct job roles to maximize cardinality.

Dinic's Algorithm & Edmonds-Karp

Constructs Level Graphs (BFS) and pushes Blocking Flows (DFS) to saturate corporate hiring quotas in O(E·√V) time.

Search History & Analytics Engine

Synchronized MRU Deque cache maintaining recent recruiter searches alongside HashMap query popularity metrics.
